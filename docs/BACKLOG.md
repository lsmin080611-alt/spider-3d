### Spider 3D — 개선·신규 증강·모드 아이디어 백로그
**사용 규칙:** 아직 코드에 적용되지 않은 아이디어와 개선 후보를 모아두는 문서입니다.
실제로 구현이 확정되어 코드에 반영된 항목은 이 문서에서 삭제하고 [기획/스펙] 마스터 설계서로 승격합니다.

#### 1. 물리·조작감·밸런스 개선사항
*(플레이하면서 느낀 아쉬운 점, 튜닝하고 싶은 수치나 판정)*
* [ ] **[Step 1] 점수제 폐지 → 보수적 곡예·콤보 XP 보상 & 5분 만렙 밸런싱**
  * **핵심 원칙:** 기존 플레이 규칙(콤보 유지, 땅·벽 충돌 회피, 고속 공격)은 유지하되 단순 점수제(`score`)를 성장/전투 직결 보상으로 전환.
  * **보수적 XP 보상 설계:** 숙련자는 이미 적 처치·웨이브 돌파 속도 자체가 빠르므로 XP 배율을 과도하게 높이지 않음(예: `2.5x` 배제). 대신 **극초반 레벨업 속도에 유의미한 수준**의 곡예·콤보 보너스(소폭 배율 또는 고정 XP 중심, 중후반 인플레이션 억제)로 설계하고, 노히트·고속 유지 시 보스전 대비 보조 보상(실드/게이지 등) 검토.
  * **5분 타이머 & 시간대 연동:** 낮 → 노을 → 야경 전환을 점수 대신 `05:00` 카운트다운에 이관.
  * **만렙 격차 목표:** 숙련자만 5분 보스전 전에 만렙(4슬롯 × Lv.3 = 12픽)을 달성해 대비할 수 있고, 비숙련자는 보스전 전 만렙에 미달하도록 XP 커브 튜닝.

#### 3. 새로운 게임 모드 변주 아이디어
*(타임 어택, 보스 러시, 무한 모드, 특수 룰 변주 등)*
* [ ] **[Step 2] 옥상 보행 → 자유낙하 → 첫 스윙 오프닝 시퀀스**
  * **핵심 흐름:** 시작 시 건물 옥상(`ROOF`)에서 걸어가 난간을 넘어 자유낙하(`DROP`) → 낙하 중 `SWING`을 한 번 걸어 받아내는 순간 본 게임(`ACTIVE`, 5분 타이머 & Wave 1) 개시.
  * **편의성:** 오프닝 구간 무적/타이머 정지, 재도전 시 즉시 도약 가능하도록 단축 입력 검토.
* [ ] **[Step 3] 5분(300초) 보스전 루프**
  * **핵심 규칙:** `05:00` 카운트다운 종료(`00:00`, 야경) 시 보스 강림.
  * **전투/성장 연계:** 만렙(12픽) 대비 숙련자와 미만렙 플레이어 간 체감 격차가 뚜렷한 보스 패턴(탄막·레이저 고속 회피 → 약점 코어 `STRIKE` → 그로기 시 `SLAM!`/필살 컷씬 폭딜).
  * **승리/패배 조건:** 보스 격파 시 런 클리어 / HP 0 시 게임 오버.

#### 4. 비주얼·사운드·연출 아이디어
*(PC-98 팔레트 스왑, 시간대 변화, 칩튠 효과음, 타격 연출 등 — T-Display-S3 60fps 기준)*
* [ ] **[Step 4] 증강 Lv.3(★각성) 완벽 플레이 1초 컷씬 액션**
  * **발동 조건:** 증강 **Lv.3(★각성)** 달성 후, 각 증강이 추구하는 플레이를 거의 완벽하게 해냈을 때 발동하는 서비스 액션 연출 (예: 최대 고도 근접 + 최대 하강 속도 근접 등 극한 조건 달성).
  * **빈도 목표:** **8분 플레이 기준 3~4회** 수준으로 희소성·임팩트 유지 (스윙 리듬 방해 방지용 엄격한 조건 + 내부 쿨타임).
  * **연출 구조 (~1초):** 기존 Case 3 `SNAP!` 시네마틱 인프라(레터박스·줌인·더치 틸트·슬로우) 확장 + 320×170 벡터/도트 전용 피니시 액션 + 종료 직후 안전 무적(`0.6s`) 및 추진 보정.
