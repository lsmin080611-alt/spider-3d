#### 2. 신규 증강(카드) & 시너지 후보
*(물리 변조 / 물리 변환 / 규칙 역전 / 기믹형 신규 카드 아이디어)*
* [ ] **[증강 시스템 개편 (Step 2 예정)]**
  * **4슬롯 상한(`MAX_AUG_SLOTS = 4`):** 4종 × Lv.3 = 12픽 완전체 구조, 슬롯 만충 시 보유 미완성 증강만 출현, HUD 4슬롯 고정 표시 및 레벨별(`NEW` / `Lv.1→2` / `Lv.2→3 ★MAX`) 동적 카드 설명.
  * **로스터 정리:** 삭제(`달의 인력`, `고압 거미줄`, `구름 앵커`), 리워크(`전격 오라` 완전 고속 주행 특화 / `체공 예열` 범위 충격파 제거·단일 극딜화 / `진공 활공` Lv.1~3 차등화), 신규(`올가미 스윙`, `연속 돌격`).
* [ ] **[연속 돌격 (가칭: 체인 러시)]** (분류: 변환)
  * **효과:** 수동 `STRIKE` 및 `연쇄 핀볼` 적중마다 `2.8s` 내 `RUSH` 스택 누적(Lv.1~3 최대 4/6/8스택, 스택당 피해 `+15%/+25%/+35%`) + 타격 후 속도 보존(`85%/95%/105%`, 방향 꺾여도 고속 유지). Lv.2 연타 중 광각 락온 보정, Lv.3 쿨다운 절반 & 4스택+ 치명타 확정.
* [ ] **[올가미 스윙 (가칭)]** (분류: 기믹 / 물리 변조)
  * **효과:** 스윙 중 지나가는 궤도 주변의 적들을 거미줄로 자동 포획해 끌고 다님(최대 5~8명, 예: Lv.1 4명 / Lv.2 6명 / Lv.3 8명). 묶인 적이 늘어날수록 무게가 증가하는 대신, **다음 `STRIKE(Shift/IO0)` 포탄 돌진이 적중하는 순간** 주 타겟과 묶인 적 전원에게 무게·포획 수 비례 초대형 광역 피해를 일괄 기폭.
  * **단점/조건:** 사냥이 지연되며, 포획된 적 1명당 유효 중력 증가로 스윙 최저점이 깊어져 바닥 충돌 위험 상승. `STRIKE` 돌진 전 건물 정면 충돌, 피격, 지면 강제 해제(`py <= 4.0~5.0`), 저속 정체 등으로 흐름이 끊기면 적들이 전부 풀려남(단, `STRIKE` 돌진 중에는 해제 면제).
  * **예상 시너지:** `낙하 운동량` + `SLAM!`(무게 증가로 급강하 가속), `도미노 연쇄 폭발`(1티어 스웜 배달 후 엘리트 원샷 중첩 폭파), `탄성 반발 슈트`(충돌 시 해제 약점 상쇄).
  * **최적화 메모 (T-Display-S3 60fps):** 묶인 적은 독립 진자 물리 대신 플레이어 궤적 기반 단순 선형 보간(Lerp) 추적 + 1px 벡터 선분으로 처리, HUD `TIED N/8` 및 줄 색상 단계 피드백 적용.
