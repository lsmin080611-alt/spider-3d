# Spider 3D 웹 스윙 로그라이크 — 마스터 게임 설계서

> **목적:** 여러 대화(`T-display-s3 spider game`, `spider graphic`, `[임시 세이브]` 등)에 흩어져 있던 Spider 3D 게임의 확정 사양과 기획을 하나로 통합·구체화한 기준 문서입니다.

---

## 1. 게임 개요 & 핵심 정체성
- **장르:** 3D 3인칭 웹 스윙 액션 + 물리 역전 로그라이크 (6분 스테이지 성장 + 보스전 아케이드 루프)
- **레퍼런스:** *Spider-Man 2 (2004)* / *Spider-Man 3 (2007)*의 진자 웹 스윙 물리 + 90년대 **PC-98 16비트 디더링 픽셀아트** 감성
- **타겟 기기:** LILYGO T-Display-S3 (ESP32-S3, 1.9인치 **320×170 가로 LCD**, 60fps 목표)
- **핵심 조작계 (2버튼 택타일 + 아날로그 조이스틱):**
  - **이동/시선:** 좌측 아날로그 조이스틱 (`IO1/IO2`, 웹: WASD / 가상 조이스틱 — 모바일 세로·가로 안쪽 여백 보정, `#joy-zone` 확장 터치 영역, `±18px` 소프트 동적 원점 지원)
  - **SWING 버튼 (`IO14` / `SPACE`):** 거미줄 부착(홀드) 및 릴리즈(이탈)
  - **STRIKE 버튼 (`IO0` / `E`, `F`, `Shift`):** 모든 공격 전용 수동 입력 (자동 호밍·자동 충돌 공격 없음)

## 2. 웹 스윙 물리 & 도시 이동 규칙
1. **순수 3D 벡터 진자 물리 (U-Swing, Corner Orbit & Slack Rope):**
   - 거미줄 부착 직후 인위적 앞쪽 끌림(Snap) 없음. 실제 거리 그대로 연결되어 자연스럽게 낙하하다 줄이 팽팽해지면 U자 원호를 그림.
   - 위치 에너지($\Delta h$)와 진입 속력을 접선 방향으로 **98.5% 보존**(하드 속도캡 제거). 기본 순항 상한 `BASE_SWING_MAX_SPD = 92.0`(퍼펙트 버프 시 `+12 = 104`) 초과분은 급제동 대신 스윙(`1.35/s`, 최저점 통과 후 상승 아크 `passedBottom && vy > 0`에서는 **`0.95/s`**)·공중(수평 `1.15/s` + 3D 공력 종단 속도 `100/다이브 110 * maxSpeedMult * vertScale` 초과 시 `1.45/s` 항력)으로 자연 수렴하여 **노증강 순항 `100` 이하 / 퍼펙트·다이브 피크 `110` 이하** 대역을 유지 (`진공 활공` 시 감쇠 0%, `오버드라이브`/`번지줄`/`초중력` 배율 연동).
   - 인위적 상승 부양 모터 없이 순수 중력 감속으로 원호를 그리며, 월드 좌표(`dx, dz`) 기준으로 플레이어와 마주한 빌딩 앞쪽 모서리에 교차 부착되어 입체적 진자 곡선을 형성 (`localZ: 28~280`, `|localX|: 6~205`, `targetWallY > py + 8`, 좌/우 입력 시 선호 측면 `-75` 가중치, `SWING` 홀드 자동 부착 및 충돌 후 `0.18s` 재부착 쿨다운). **저고도(`py < 55m`) 스윙** 시에는 `idealZ`를 가깝게 당기고 각도가 선(수직에 가까운) 앵커에 우선 가중치를 부여하며, 지면 여유(`SAFE_SKIM_Y`) 확보용 자동 줄감기 속도를 현재 속력 비례(**`max(55, totalSpeed * 1.2)`**, `py < 22m` 긴급 시 `max(1.25x, 78)`)로 동적 스케일링해 고속 바닥 충돌을 완화.
   - **아날로그 조이스틱 3구간 스윙 제어 & 모서리 연속 회전(Orbit):**
     - 좌/우 조향 시 슬랙 구간을 포함한 스윙 전 구간에서 **수평 속도 직접 선회(`1.35 rad/s * turnMult`)** + 횡추력(`56.0 * turnMult`) + 기민한 카메라 추종(`8.5`)으로 장애물 회피력을 확보. 앵커 반대쪽 강선회(`turn * currentAnchorSide < -0.25`) 시 바깥쪽으로 줄 여유(`+22 m/s`)를 완화해 벽 충돌 회피를 지원.
     - 전진(`fwd > 0.15`)은 기본 접선 추진(`22.0 * swingPushMult`, 상승 아크에서는 **3D 진행 접선 벡터**로 전환)으로 동작하며, **정면 끝까지 밀 때(`fwd > 0.65 && |turn| < 0.35`)**만 연속 비례 줄 당기기(기본 `20 m/s`, 장력 상승 아크 `26 m/s`, **최소 반경 `46m` 하한**으로 벽 빨림 차단)가 작동. 최저점 통과 후 상승 구간(`passedBottom && py > 10m`)에서 줄당김 유지 시 감긴 길이에 비례한 **접선 가속(`+0.85x * swingPushMult`) + 상승 펌프(`vy += +0.65x * bungeeBounce`)**를 부여하되, 총속력이 `maxSwingSpd + 4`를 초과하면 상승(`vy`)을 보존하고 수평 성분만 축소(수평→고도 전환)해 노증강 속도 밸런스를 지키면서 고도 확보력을 +25~30% 강화. 살짝 전진하거나 좌/우·대각선(`|turn| >= 0.35`) 입력 시에는 줄 길이가 고정되어 원하는 반경 그대로 **모서리 연속 회전** 가능 (`fwd < -0.30` 후진 시 연속 비례 줄 풀기 최대 `28 m/s`).
     - 정점/거리 자동 해제를 제거해 `SWING` 홀드 중 모서리 회전 플레이를 보장(수동 릴리즈, `STRIKE` 전환, 바닥 안전 방어, 정면 충돌/탄성 반발 시에만 해제).
2. **스위트 스폿 릴리즈, 에이펙스 플로트(Apex Float) & 320×170 그래플링 피드백:**
   - 최저점 통과(`passedBottom`) 후 상승 후반부 구간에서 릴리즈 시 **PERFECT RELEASE** 발동 (탄성 킥 `12+8*d` · `vy` 상한 **`88 * bungeeBounce`** + 3D 피크 상한 `108 * maxSpeedMult` 초과 시 `vy` 보존·수평 정규화 + 스타일 랭크 게이지 `+12` & `3.4s` 화력 버프; 일반 릴리즈 `vy` 상한 **`73 * bungeeBounce`** · 3D 피크 상한 `98 * maxSpeedMult`). `PERFECT` 구간 종료 직후 `0.09s` 유예(`perfectGraceTimer`) 및 짧은 스윙(`0.10s+`, `vy > 4`, `vy` 상한 `52 * bungeeBounce`) 가벼운 도약 보정 적용.
   - 320×170 초경량 벡터 피드백: 화면 밖 앵커 테두리 방향 화살표, 부착 직후 `0.05s` 거미줄 사출 연출, 느슨한 구간(2단 처짐선) vs 장력 구간(직선) 시각 구분.
   - **비대칭 3단계 자유낙하 중력 커브 (`BASE_GRAVITY = 64.0`) & 하강 전용 활강:** 상승(`vy > 8`)은 기본 중력(`1.0x`), 정점 구간(`-4 <= vy <= 8`, 고도 `45m+`)은 중력 `0.52x`(약 0.35초)로 짧고 선명한 무중력(Apex Float)을 제공하며, 하강 전환(`vy < -4`) 즉시 중력이 `1.40x → 최대 1.75x`(낙하 속도 비례)로 강해져 리드미컬한 추락 긴장감을 형성. 활강(`isGliding`, `0.16x` 중력 · 종단 `-9 m/s`)은 **하강 중(`vy <= 0`)에만 적용**되어 상승 중 `S` 입력 시 정상 정점 도달 후 자연스럽게 활강으로 전환. 다이브 시 하강 중력에 추가 가속(`+42 * forwardInput`) 적용. `aug.gravityMult`는 전 구간에 일관 반영.
3. **하이리스크-하이리턴 스침 판정 & 다이내믹 카메라:**
   - **Ground Skim:** 고도 18m 이하(`LOW SWING!`), 8m 이하(`DANGER SKIM!!`) 통과 시 불꽃·충격파 연출과 가속·스타일 랭크 게이지 상승(`+6~14/s`, 캐년 동시 스침 추가 `+8/s`).
   - **Wall Slide / Wall Skim:** 빌딩 모서리에 스칠 때 정면 충돌 판정 각도를 좁히고 자연스럽게 미끄러지며 가속·스타일 랭크 게이지 상승(`+6` / `+6~14/s`).
   - 속도와 저공 정도에 따라 3인칭 스프링 카메라의 시야각(FOV) 및 미세 셰이크가 동적으로 변화. 고공 급강하(`isDiving` / `vy < -18`) 시 하향 피치 강화 + 발밑 `SLAM` 락온 표적 쪽 35% 시선 보정, 저공 고속 주행(`py < 30m`, `SPD > 45`) 시 수평 시야 보정으로 앞길 가시성 확보.
4. **도시 구조, 고도 상한 & 시네마틱 옥상 오프닝 (`ROOF_WAIT → ROOF_WALK → DROP_INTRO → DROP_CATCH → ACTIVE`):**
   - 바둑판 배열 탈피: 초광폭 중앙 대로(폭 120m+), 대형 공원 광장, 저층 구역(70~120m), 초고층 마천루(280~420m) 혼합 배치.
   - **최대 고도 (`MAX_ALTITUDE`):** 650m까지 개방, 구름층은 240~480m 상공 배치.
   - **건물 관통 0% 5-Cut 영화적 옥상 오프닝 (최초 실행 `~5.6초` 풀 컷신 / 재도전 `1.50초` 압축 — 안 B, 완전 제어 불가 컷신):**
     - 구름 위 **`510m` 오프닝 전용 첨탑 전망대**(`18×18×510m`, 황금 난간 트림 + 좌우 점멸 항공등; 본 게임 `ACTIVE` 진입 시 도심으로 자연 정리) 및 전방 좌/우 앵커 보장 초고층 타워(`380m / 365m`) 배치.
     - **`ROOF_WAIT → Cut 1 (ROOF_WALK, ~1.55s)`:** `510m` 옥상 등 뒤 Over-the-Shoulder 와이드 샷으로 맨해튼 마천루 조망 → 아무 입력 시 타워 **바깥쪽 측면 허공(`x=+16.5`)**으로 매치 컷 전환해 옆모습 보행(`ROOF_WALK_A/B`) + 난간 끝 **`0.40s` 정지(`ROOF_IDLE`)**.
     - **`Cut 2~5 (DROP_INTRO, 최초 4.05s / 재도전 395m 개방 허공 1.50s)`:**
       - **Cut 2 (`0.00~1.15s`):** 난간 앞쪽 개방 허공(`z>-91`)으로 부드럽게 도약 낙하(`vz=22`), 카메라는 **타워 바깥쪽 측면 허공(`x=16.5, z=-84`)**에 머물며 왼쪽 유리 외벽과 맨해튼 마천루를 배경으로 추적 (카메라·시선 건물 관통 0%).
       - **Cut 3 (`1.15~2.35s`):** 타워에서 26m+ 앞쪽 허공으로 빠져나온 캐릭터를 측면→등 뒤 상공으로 휘감아 들어가며 수직 급추격(FOV `208→128`) + `495m→310m` 구름층 돌파 `2번 구름` 스프라이트 좌우 상승 스윕 & 수직 스피드라인.
       - **Cut 4 (`2.35~3.45s`, 스파이더버스 오마주):** 매치 컷으로 **앞쪽 아래 역방향 올려다보는 앵글** 전환 + 미세 슬로우 공중 1회전 플립 → 클로즈업 전용 **`DROP_HERO`** 포즈 홀드(더치 틸트 `-0.22` + 점선 잔상 + 방사형 코믹 집중선).
       - **Cut 5 (`3.45~4.05s`):** 매치 컷으로 등 뒤 3인칭 `DIVE` 스냅 + `14px` 레터박스 해제 → 고도 **`~240m`** 진입.
     - **`DROP_CATCH` (제어 가능 자유낙하, `~1.7~2.0s`):** 고도 `200~95m` `[ SWING NOW! ]`(`SWEET CATCH!! +10 STYLE`), `95m` 이하 `[ LAST CHANCE! SWING!! ]`(`DAREBLITZ CATCH!! +18 STYLE`, 저공 안전 로프 여유 보정). 첫 `SWING` 부착 즉시 **`ACTIVE`** 개시(`06:00` 타이머 & Wave 1), 끝까지 스윙 실패로 지면(`py < 2.5`) 충돌 시 **`MISSED THE SWING!` 즉시 게임 오버**.
5. **절대 유지해야 할 물리 방어 규칙:**
   - **바닥 로켓 사출 버그 차단:** 스윙 중 지면(`py <= 4.0~5.0`) 접촉 시 즉시 거미줄 강제 해제 및 수직 속도 상한/초기화로 하늘로 튀어 오르는 현상 원천 차단.
   - **건물 정면 충돌:** 진행 속도 감속 후 벽 바깥으로 안전하게 슬라이드/튕겨나감(탄성 반발 증강 없을 시).

## 3. 수동 2버튼 전투(STRIKE), 5단계 스타일 랭크 & 6분 성장 시스템
### 3-1. 속도·에너지 기반 3가지 STRIKE 분기 & 통합 속도 데미지 스케일링
| 분기 | 발동 조건 | 동작 & 연출 | 후처리 |
| :--- | :--- | :--- | :--- |
| **Case 1: SLAM!** (주황) | 고속/급강하 중 (`vy < -22`, 고도 `42m+`) | 현재 하강 궤적을 크게 꺾지 않는 약한 락온(+ 직하방 원뿔 표적 안정 포착)으로 자연스럽게 내리찍기 | 적중 시 다음 스윙으로 이어가기 좋은 상향 반동 (`SLAM REBOUND!`) |
| **Case 2: ZIP-HIT** (시안) | 초고속 (`SPD >= 160`) | 공중 정지 없이 관성을 유지하며 거미줄 발사 → 적중 즉시 **1.42배 가속 유도 돌진** (`WEB-ZIP RUSH!!`) | 후방 장애물 여부에 따라 관통/저반동 분기 |
| **Case 3: SNAP!** (마젠타) | 저·중속 (`SPD < 160`) | 속도에 반비례하는 짧은 공중 정지(`0.08~0.46s`) + 시점 줌인/더치 틸트/레터박스/집중선 + **4종 랜덤 카툰 포즈**(양손 당기기, 슈퍼맨 펀치, 드롭킥, 회전 웹스핀) 후 잡아당겨 돌진 | 후방 장애물 여부에 따라 관통/저반동 분기 |

- **전 STRIKE 통합 속도 데미지 스케일링 (`getSpeedDamageMult(spd)`, 상한 캡 없음):**
  - `SPD 0 ~ 45`: `0.70x ~ 1.00x` (`18 ~ 26 dmg` — 노증강 저속 `SHIFT` 연타로 2/3단계 몹 쉽게 처치 불가)
  - `SPD 45 ~ 95`: `1.00x ~ 3.20x` (비선형 가속 커브 — 고속 스윙 + `B`랭크 이상에서 노증강 2단계 원샷 가능)
  - `SPD 95+`: 상한 없이 `SPD`당 `+0.028x` 연속 상승 (`SPD 120 → 3.90x`, `SPD 150 → 4.74x`, `SPD 200 → 6.14x`)
  - **적용 범위:** Case 1(`SLAM!`, `effSpd = max(entrySpd, fallSpd * 1.15)` × 급강하 보정 `1.15~1.40x`), Case 2(`ZIP-HIT`), Case 3(`SNAP!`), **`연쇄 핀볼`**까지 모든 STRIKE 공격에 일관 적용.
- **후방 공간 판정:** 타격 후 적 뒤쪽(44m 이내)에 땅·건물이 있으면 충돌 방지를 위해 저반동(`SAFE REBOUND!`), 탁 트여 있으면 시원하게 관통(`PIERCE THROUGH!!`).

### 3-2. 5단계 스타일 랭크 (`D → C → B → A → S`) & 배경·화력 연동 (점수제 폐지)
- 기존 단순 점수제(`score`, `bestScore`)를 폐지하고 **스타일 게이지(`stylePoints`, `0~100`)** 기반 5단계 랭크로 전환.
