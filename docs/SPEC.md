# Spider 3D 웹 스윙 로그라이크 — 마스터 게임 설계서

> **목적:** 여러 대화(`T-display-s3 spider game`, `spider graphic`, `[임시 세이브]` 등)에 흩어져 있던 Spider 3D 게임의 확정 사양과 기획을 하나로 통합·구체화한 기준 문서입니다.

---

## 1. 게임 개요 & 핵심 정체성
- **장르:** 3D 3인칭 웹 스윙 액션 + 물리 역전 로그라이크 (1판 3~5분 아케이드 루프)
- **레퍼런스:** *Spider-Man 2 (2004)* / *Spider-Man 3 (2007)*의 진자 웹 스윙 물리 + 90년대 **PC-98 16비트 디더링 픽셀아트** 감성
- **타겟 기기:** LILYGO T-Display-S3 (ESP32-S3, 1.9인치 **320×170 가로 LCD**, 60fps 목표)
- **핵심 조작계 (2버튼 택타일 + 아날로그 조이스틱):**
  - **이동/시선:** 좌측 아날로그 조이스틱 (`IO1/IO2`, 웹: WASD / 가상 조이스틱 — 모바일 세로·가로 안쪽 여백 보정, `#joy-zone` 확장 터치 영역, `±18px` 소프트 동적 원점 지원)
  - **SWING 버튼 (`IO14` / `SPACE`):** 거미줄 부착(홀드) 및 릴리즈(이탈)
  - **STRIKE 버튼 (`IO0` / `E`, `F`, `Shift`):** 모든 공격 전용 수동 입력 (자동 호밍·자동 충돌 공격 없음)

## 2. 웹 스윙 물리 & 도시 이동 규칙
1. **순수 3D 벡터 진자 물리 (U-Swing & Slack Rope):**
   - 거미줄 부착 직후 인위적 앞쪽 끌림(Snap) 없음. 실제 거리 그대로 연결되어 자연스럽게 낙하하다 줄이 팽팽해지면 U자 원호를 그림.
   - 위치 에너지($\Delta h$)를 최저점 통과 시 전방 가로 속도($v_{\text{horiz}}$)로 치환. **스윙을 크게·깊게 할수록(큰 낙차)** 릴리즈 시 더 높고 빠르게 솟구침.
   - 빌딩 좌/우 실제 벽면에 거미줄이 교차 부착되어 입체적 진자 곡선을 형성.
2. **스위트 스폿 릴리즈 & 에이펙스 플로트(Apex Float):**
   - 최저점 통과(`passedBottom`) 후 상승 후반부 구간에서 릴리즈 시 **PERFECT RELEASE** 발동 (공중제비 슬링샷 + 보너스 XP).
   - 정점(Apex, 수직 속도 $|v_y| < 22$ 구간)에서 중력을 약 45% 완화해 부드러운 체공 시간(Hang-Time) 제공.
3. **하이리스크-하이리턴 스침 판정 & 다이내믹 카메라:**
   - **Ground Skim:** 고도 18m 이하(`LOW SWING!`), 8m 이하(`DANGER SKIM!!`) 통과 시 불꽃·충격파 연출과 가속·XP 보너스.
   - **Wall Slide / Wall Skim:** 빌딩 모서리에 스칠 때 정면 충돌 판정 각도를 좁히고 자연스럽게 미끄러지며 가속·XP 획득.
   - 속도와 저공 정도에 따라 3인칭 스프링 카메라의 시야각(FOV) 및 미세 셰이크가 동적으로 변화.
4. **도시 구조 & 고도 상한:**
   - 바둑판 배열 탈피: 초광폭 중앙 대로(폭 120m+), 대형 공원 광장, 저층 구역(70~120m), 초고층 마천루(280~420m) 혼합 배치.
   - **최대 고도 (`MAX_ALTITUDE`):** 650m까지 개방, 구름층은 240~480m 상공 배치.
5. **절대 유지해야 할 물리 방어 규칙:**
   - **바닥 로켓 사출 버그 차단:** 스윙 중 지면(`py <= 4.0~5.0`) 접촉 시 즉시 거미줄 강제 해제 및 수직 속도 상한/초기화로 하늘로 튀어 오르는 현상 원천 차단.
   - **건물 정면 충돌:** 진행 속도 감속 후 벽 바깥으로 안전하게 슬라이드/튕겨나감(탄성 반발 증강 없을 시).

## 3. 수동 2버튼 전투(STRIKE) & 실력 기반 성장 시스템
### 3-1. 속도·에너지 기반 3가지 STRIKE 분기
| 분기 | 발동 조건 | 동작 & 연출 | 후처리 |
| :--- | :--- | :--- | :--- |
| **Case 1: SLAM!** (주황) | 고속/급강하 중 (`vy < -28`) | 현재 하강 궤적을 크게 꺾지 않는 약한 락온으로 자연스럽게 내리찍기 | 적중 시 다음 스윙으로 이어가기 좋은 상향 반동 (`SLAM REBOUND!`) |
| **Case 2: ZIP-HIT** (시안) | 중·고속 (`SPD >= 52`) | 공중 정지 없이 관성을 유지하며 거미줄 발사 → 적중 즉시 **1.42배 가속 유도 돌진** (`WEB-ZIP RUSH!!`) | 후방 장애물 여부에 따라 관통/저반동 분기 |
| **Case 3: SNAP!** (마젠타) | 저속 (`SPD < 52`) | 잠시 공중 정지(약 0.28s) + 시점 줌인/더치 틸트/레터박스/집중선 + **4종 랜덤 카툰 포즈**(양손 당기기, 슈퍼맨 펀치, 드롭킥, 회전 웹스핀) 후 잡아당겨 돌진 | 후방 장애물 여부에 따라 관통/저반동 분기 |

- **후방 공간 판정:** 타격 후 적 뒤쪽(44m 이내)에 땅·건물이 있으면 충돌 방지를 위해 저반동(`SAFE REBOUND!`), 탁 트여 있으면 시원하게 관통(`PIERCE THROUGH!!`).

### 3-2. 적 티어 & 실력 기반 경험치(XP) 가속 성장
- **초반 티어 제한:** Wave 1~2에서는 3단계 엘리트 몹 제외, Wave 3부터 등장.
  - **1티어:** 스웜 드론 편대 (다수 처치·연쇄 폭파 쾌감용)
  - **2티어:** 중형 몹 (HP 92~110) — 근접 저속 STRIKE 난타 시 26 dmg(3~4타 필요), **고속 가속(SPD 95+) / 퍼펙트 릴리즈 / 스침 직후 / Case 1 내리찍기** 시 초반 노증강에서도 **원샷(100~155 dmg)** 가능. 원샷 가능 조건 충족 시 조준선에 황금색 `1-HIT!` 표시.
  - **3티어:** 엘리트 몹 (고공 코어 / 빌딩 기생 터렛 등)
- **실력 기반 XP 수급:** 웨이브 클리어만 기다리지 않고 `PERFECT RELEASE(+24~38XP)`, `DIVE BOOST(+14~34XP)`, `WALL SLIDE(+10XP)`, 벽/바닥 스침, 고속 원샷 배율(`1.3x~2.5x`)로 웨이브 도중에도 즉시 레벨업 및 증강 선택 가능.

## 4. 로그라이크 증강(카드) 시스템
### 4-1. 설계 철학: '유기적 물리 역전' (단독 범용 + 교차 시너지)
전용 속성 스택 대신 물리 엔진의 공용 변수(**속도, 중력, 체공·고도, 충돌/접촉**)를 화폐로 사용하여, 1장만 집어도 체감되고 조합 시 단점이 무기로 역전되도록 설계.

1. **물리 변조 (뚜렷한 유불리 트레이드오프):**
   - `초중력 슈트`: 중력 1.6배, 기본 파괴력 +45% (단점: 빠른 추락)
   - `달의 인력`: 중력 0.55배, 선회·유도 범위 1.6배 (단점: 기본 가속 느림)
   - `오버드라이브`: 최대 속도 1.5배, 추진력 +35% (단점: 코너링 둔화, 벽 충돌 위험)
   - `고탄성 번지줄`: 상승 반동 1.45배 (단점: 최저점이 깊게 처짐)
2. **물리 변환 (범용 화력 스케일링):**
   - `체공 예열`: 공중 체공 1초당 데미지 +35% & 범위 +20% 누적
   - `낙하 운동량`: 직전 최대 하강 속도(`-vy`)에 비례해 데미지·관통력 증가
   - `마찰 과열`: Ground/Wall Skim 유지 시 속도 +30%/초 + 화염 파동
   - `장력 슬링샷`: 스위트 스폿 릴리즈 시 속도·데미지 최대 1.6배
3. **규칙 역전 (범용 보험 ↔ 단점 역전 엔진):**
   - `탄성 반발 슈트`: 건물 벽면 정면 충돌 시에만 발동(바닥 충돌 반사 제외). 반사 속도 배율 Lv.1(`0.9x`) / Lv.2(`1.0x`) / Lv.3(`1.1x`) + 충격파. 최대 충전 Lv.1(`1회`) / Lv.2(`2회`) / Lv.3(`3회`)이며 스윙 시작 자동 리필 없이 `STRIKE` 적중 또는 `PERFECT RELEASE` 성공 시 해당 레벨 최대치로 전량 재충전. 320×170 HUD에 `4×4` 도트(1~3개)로 남은 충전량 표시 *(초중력/오버드라이브 단점 역전)*
   - `진공 활공`: 공중 공기저항 0% (감속 불가) *(달의 인력 단점 보완)*
   - `핀볼 리바운드`: 적중 시 1.2배 반동 + 체공 스택 유지
   - `구름 앵커`: **2번 구름에도 거미줄 부착 가능** + 고도 140m+ 릴리즈 시 즉시 강화 타격
4. **화면이 터지는 기믹형 증강 (초경량 벡터/도트 연출):**
   - `연쇄 튕기기 (자동 핀볼)`: STRIKE 적중 후 반경 95m 내 최근접 적으로 자동 연쇄 타격 (Lv.1: 2연쇄 → Lv.3: 5연쇄)
   - `스윙 오라`: 속도 65+ 이동 시 반경 28~48m 내 적 지속 광역 피해
   - `고압 거미줄 (웹 단두대)`: 매달린 거미줄 선분 자체에 공격 판정 부여
   - `도미노 연쇄 폭발`: 적 처치 시 반경 45m 2차 폭발로 스웜 편대 연쇄 폭파

### 4-2. 증강 선택 UI 오입력 방지 규칙
- `SWING(SPACE / IO14)` 버튼은 증강 확정에서 **완전 제외** (스윙하려다 잘못 고르는 사고 방지).
- 확정은 `STRIKE(E/F/Shift)`, `Enter`, `1/2/3`, 카드 터치로만 작동.
- 선택 창 오픈 직후 **0.65초 입력 잠금 (`draftLockTimer`)** 및 하단 대기 게이지 표시.

## 5. PC-98 빈티지 도트 비주얼 & 60fps 최적화 사양
- **아트 스타일:** 16비트 NEC PC-9801 스타일 (제한 팔레트 + 2×2 베이어 디더링 + 짙은 남색 `#1a2854` 1px 외곽선 + 선택적 스캔라인).
- **구름 에셋 통일:** **`2번 구름`** (납작한 바닥, 흰색 하이라이트 + 하늘/연보라 디더링 음영, `44×18` 크로마키 스프라이트)으로 전체 통일.
- **배경 & 도시 디테일:**
  - `1024×160` 도트 360° 파노라마 스트립 (`camYaw` 연동 스크롤, 베이어 디더링 하늘 + 태양 후광 + 맨해튼 스카이라인·현수교).
  - 사전 베이크된 디더링 타일 패턴 건물(5종 팔레트, 벽돌, 1층 어닝, 옥상 물탱크·펜트하우스), 50% 체커보드 그림자, 도로 위 옐로우 택시.
- **캐릭터 스프라이트:** `24×28` 도트 스파이더맨 스킨 (기본 5종 포즈 + Case 3 카툰 STRIKE 4종 포즈).
- **ESP32-S3 60fps 대응 원칙:** 실시간 셰이더 배제, 사전 베이크 패턴·크로마키 스프라이트 블릿·벡터 선분/원형 이펙트(번개선, 충격파 링, 스파크) 위주 구성.
