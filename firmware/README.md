# Spider 3D — LILYGO T-Display-S3 Firmware (Phase 1)

**Phase 1 목표:** 하드웨어 브링업(아날로그 조이스틱 · 내장/외장 4버튼 · 수동 부저) + 맨해튼 3D 도시 & 웹 스윙 물리 60fps 실기기 검증

---

## 1. 배선도 (`include/pins.h`)

ST7789 8-bit 병렬 LCD 핀(`IO5~9`, `IO15`, `IO38~42`, `IO45~48`)과 충돌하지 않는 안전한 헤더 핀 기준입니다.

| 부품 | T-Display-S3 핀 | 연결 | 비고 |
| :--- | :---: | :--- | :--- |
| **아날로그 조이스틱 VCC / GND** | `3V3` / `GND` | 전원 | 반드시 **3.3V** 사용 (5V 금지!) |
| **아날로그 조이스틱 VRx (좌/우)** | **`IO1`** | ADC1 입력 | 부팅 시 자동 영점 캘리브레이션 |
| **아날로그 조이스틱 VRy (전/후)** | **`IO2`** | ADC1 입력 | 방향이 반대면 `pins.h`의 `JOY_INVERT_Y` 변경 |
| **SWING (내장 + 외장)** | `IO14` (내장) + **`IO3`** (외장) | 스위치 한쪽 → `IO3`, 반대쪽 → `GND` | 내장/외장 **동시 사용(OR)** |
| **STRIKE (내장 + 외장)** | `IO0` (내장) + **`IO10`** (외장) | 스위치 한쪽 → `IO10`, 반대쪽 → `GND` | `IO0`는 전원 켜는 순간 누르고 있지 말 것 |
| **수동 피에조 부저** | **`IO11`** (+), `GND` (-) | PWM(`ledcWriteTone`) | 수동(패시브) 부저 전용 |

> 핀 번호를 다르게 배선했다면 [`include/pins.h`](include/pins.h) 상단 상수만 바꾸고 다시 업로드하면 됩니다.

## 2. VSCode + PlatformIO 업로드 방법

1. VSCode에서 **`PlatformIO IDE`** 확장 프로그램 설치
2. VSCode에서 `File → Open Folder...`로 이 저장소 안의 **`firmware/`** 폴더 열기
3. T-Display-S3를 USB-C 데이터 케이블로 PC에 연결
4. VSCode 하단 파란색 상태바의 **`→` (PlatformIO: Upload)** 클릭
5. *(선택)* 하단 플러그 아이콘(**Serial Monitor**, `115200 baud`)을 열면 FPS·프레임 시간(µs)·조이스틱 ADC·버튼 상태를 실시간으로 볼 수 있습니다.

> **업로드가 안 잡힐 때 (다운로드 모드 수동 진입):**
> 내장 `IO0`(BOOT) 버튼을 누른 상태에서 `RST` 버튼을 한 번 짧게 눌렀다가 떼고, `IO0`를 뗀 뒤 다시 Upload를 누르세요.

## 3. Phase 1 조작법 & 하드웨어 점검 방법

- **SWING (`IO14` / `IO3`)**:
  - 공중에서 홀드 → 전방 빌딩에 거미줄 발사 & 3D 진자 스윙
  - 상승 구간(`PERFECT!`, 화면 테두리 시안 점멸)에서 떼기 → 슬링샷 부스트 + 퍼펙트 효과음
  - 바닥(`GROUND`)에서 누르기 → 하이 점프 + 자동 웹 캐치
- **조이스틱 (`IO1` / `IO2`)**:
  - 좌/우: 스윙 카빙 선회 & 빌딩 회피
  - 앞(끝까지): 줄 당김 & 상승 펌프 / 공중 하강 시 다이브
  - 뒤: 줄 풀기 / 공중 하강 시 웹-윙 활강(`GLIDE`)
- **STRIKE (`IO0` / `IO10`)** *(Phase 1 테스트 유틸)*:
  - **짧게 누르기:** 부저 테스트음(`IO11`) + 스파크 + 우상단 하드웨어 진단 HUD ON/OFF
  - **`SWING` 누른 채 `STRIKE` 탭:** 부저 모드 순환 (`SFX` → `ALL(BGM+SFX)` → `OFF`)
  - **1.1초 길게 누르기:** 조이스틱 중앙 재캘리브레이션 + 124m 시작 지점으로 리셋
